# Homepage font assets

The homepage self-hosts the same typefaces used by NextReach Studio:

- Cabinet Grotesk variable, from Indian Type Foundry / Fontshare: https://www.fontshare.com/fonts/cabinet-grotesk
- Plus Jakarta Sans variable (Latin and Latin extended), from Google Fonts: https://fonts.google.com/specimen/Plus+Jakarta+Sans
- JetBrains Mono variable (Latin), from Google Fonts: https://fonts.google.com/specimen/JetBrains+Mono

Cabinet Grotesk is distributed under Fontshare's free font license. Plus Jakarta Sans and JetBrains Mono are distributed under the SIL Open Font License.
