# NextReach Studio / Visual Brand Book

30 visual pages for the studio's identity and future campaigns. Edition: 7 October 2026.

## Start here

- **Read:** `/brand/book` or `NextReach-Studio-Brand-Book.pdf`.
- **Design:** use the SVGs in `templates/`; each contains editable text and embedded WOFF2 fonts. The adjacent PNGs are ready-to-use previews at native dimensions.
- **Implement:** import `tokens.css` or read `tokens.json`.
- **Identify:** use the supplied files in `logos/`; never redraw the symbol.

## Editing the ad masters

The four masters are portrait offer (1080 × 1350), square brand (1080 × 1080), vertical story (1080 × 1920), and landscape brand (1200 × 628). A 1200 × 630 link-preview variant is also supplied.

Edit live `<text>` elements in the SVG source or a vector editor. The embedded fonts render in a browser. Some desktop editors ignore embedded web fonts: install the matching original Cabinet Grotesk, Plus Jakarta Sans, and JetBrains Mono fonts before editing there. Font origins and licenses are documented in `fonts/README.md`. Keep an editable version before outlining text for print.

The logo image in each template is the supplied raster lockup embedded into the file, so its appearance is stable. Replace it with the supplied vector master for exceptionally large print work, preserving its proportions and clear space.

The offer master uses the documented starting website price of ₹5,000. Delivery depends on approved content, assets, and scope. Check `/fast-websites` for current prices and inclusions before reusing a campaign. Other layouts are brand examples, not testimonials or measured client results.

## Production rules

Use sRGB for digital exports. Check a 360 px phone preview, actual contrast, current platform safe areas, and the destination URL. Use printer-specific ICC conversion, 3 mm bleed, and 300 ppi placed raster images for press artwork. The book PDF is a visual reference, not a press-ready stationery file.
